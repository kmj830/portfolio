Engineering Standard

시스템 설계 및 아키텍처 원칙

코드를 작성할 때 타협하지 않는 백엔드 엔지니어링 철학입니다.

01. Architecture

도메인 주도 격리 & 계층 분리

Controller, Service, Repository, Entity 간의 책임을 철저히 분리하고 DTO를 통한 데이터 은닉을 보장합니다. 비즈니스 로직이 프레임워크나 외부 인프라에 종속되지 않도록 설계합니다.

02. Performance

지연 시간 최소화 & 캐싱 전략

FindBook 프로젝트에서 싱가포르 원격 DB의 지연을 극복하기 위해 2.5초 인메모리 캐싱 레이어를 적용해 1ms 응답 속도를 달성했듯, 데이터 접근 병목을 분석하고 최적의 캐시를 배치합니다.

03. Robustness

엣지-클라우드 무결성 & 노이즈 방어

DogMate IoT 시스템에서 초음파 센서 튐 현상을 잡기 위해 하드웨어 메디안 필터를 적용하고 API 결측치 방어 로직을 짰듯이, 불완전한 네트워크와 하드웨어 노이즈 상황에서도 무너지지 않는 방어적 코드를 작성합니다.

04. Cloud Native

컨테이너화 & OpenAPI 문서화

Docker를 활용해 로컬 환경과 프로덕션 클라우드(Cloud Run, Render)의 일관성을 유지하며, 모든 API는 Swagger/OpenAPI 3.0 스키마로 표준화하여 협업 비용을 '0'으로 만듭니다.
