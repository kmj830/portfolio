Core Competencies

핵심 엔지니어링 역량

프로젝트에서 입증된 실무 중심의 기술적 강점입니다.

01. API Architecture

RESTful API 설계 & OpenAPI 3.0 표준화

Controller-Service-Repository 계층 분리와 엄격한 DTO 설계를 통해 비즈니스 로직을 격리합니다. Swagger/OpenAPI 명세를 사전에 구축하여 프론트엔드 및 iOS 네이티브 앱과의 연동 비용을 최소화합니다.

02. Data Modeling

RDBMS 설계 & 인메모리 캐싱

PostgreSQL, Supabase 기반의 관계형 데이터 모델링과 JPA 영속성 관리를 다룹니다. FindBook에서 반복 바코드 조회 부하를 줄이기 위해 인메모리 핫 캐시 계층을 배치했듯, 데이터 특성에 맞는 최적화 구조를 설계합니다.

03. Edge & Telemetry

엣지 AI & 하드웨어 노이즈 필터링

라즈베리파이 환경에서 YAMNet 음향 AI를 활용한 짖음 분류를 수행하고, 초음파 센서 노이즈를 잡기 위한 메디안 필터를 구현했습니다. 불완전한 하드웨어 환경에서도 신뢰성 높은 데이터를 클라우드로 전송합니다.

04. Cloud & Container

Docker 컨테이너화 & 서버리스 배포

Google Cloud Run, Docker, Render 환경을 활용해 로컬과 프로덕션 환경의 일관성을 보장합니다. HTTPS 환경의 상대 경로 Base URL 처리 등 클라우드 배포 시 발생하는 실무 이슈를 직접 해결합니다.
